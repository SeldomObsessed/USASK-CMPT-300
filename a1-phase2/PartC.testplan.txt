Here is an overview of my test plan. I'll go function level tests to begin, what
should be checked for each file, and then I'll go higher level things are
interacting tests after that.

ListCreate()
- test calling once on program start
- test calling three times (to exceed the LIST_MIN allocation and test realloc)

ListCount()
- test NULL list arg
- test list arg with no nodes
- test list arg with 1 node
- test list arg with 2 nodes
- test list arg after deletion from 2 -> 1
- test list arg after deletion from 1 -> 0
- test a ListFree()'d list to see what happens with an invalid list

ListFirst()
- test NULL list arg
- test list arg with no nodes
- test list arg with 1 node
- test list arg with 2 nodes
- test list arg after deletion of initial first node
- test list arg after deletion from 1 -> 0
- test a ListFree()'d list to see what happens with an invalid list

ListLast()
- test NULL list arg
- test list arg with no nodes
- test list arg with 1 node
- test list arg with 2 nodes
- test list arg after deletion of initial last node
- test list arg after deletion from 1 -> 0
- test a ListFree()'d list to see what happens with an invalid list

ListNext()
- test NULL list arg
- test list arg with no nodes
- test list arg with 2 nodes when curr==NULL
- test list arg with 2 nodes when curr==first
- test list arg with 2 nodes when curr==last
- test a ListFree()'d list to see what happens with an invalid list

ListPrev()
- test NULL list arg
- test list arg with no nodes
- test list arg with 2 nodes when curr==NULL
- test list arg with 2 nodes when curr==last
- test list arg with 2 nodes when curr==first
- test a ListFree()'d list to see what happens with an invalid list

ListCurr()
- test NULL list arg
- test list arg with no nodes
- test list arg with 2 nodes when curr==NULL
- test list arg with 2 nodes when curr==first
- test list arg with 2 nodes, curr==last but run ListRemove() before ListCurr()
- test list arg with 2 nodes, curr==first but run ListRemove() before ListCurr()
