Summary and Goals
  build 4 executables which implement the same core task on multiple concurrency
  models. 

  A.1 (WINDOWS threads) parent creates M child threads; parent sleeps till
  deadline, then signals children to stop using a global shared flag. each child
  prints elapsed time and its call count on exit.
  A.2 (UBC threads) similair to A.1 but parent kills children at deadline. Then
  parent reports stats for killed children.
  A.3 (POSIX threads) similar to A.2 but POSIX pthread_* semantics. thread
  termination method may differ.
  A.4 (BONUS, UNIX processes + signals) implement with processes, a timer
  process that sends SIGALRM to parent+children and children use a SIGALRM
  handler to print stats.

Square() design 
  square.c provides int Square(int N) exactly as given, but also increases
  counter on each invocation.
  We use a global pre-thread counter array index variable accessible to 
  Square() We can pass a global integer threadIndex that threads set 
  immediately after starting. The invocation counter increments at entry of 
  Square().
  

Error handling and edge cases
  input validation: ensure threads >= 1, deadline >= 0, size >= 1
  deadline == 0 behaviour: parent immediately sets keepRunning=false or
  sends kills. 
  child finishes before deadline: should print finished normally.
  handle resource exhaustion: cap threads to reasonable maximmum: 1024
  ensure Square recursion depth does not overflow stack for large size. Test for
  maximmum size.

Testing plan
  small run: partA1 2 5 10 : check children finish normally and counters make
  sense.
  deadline early: partA1 2 5 10000 : ensure children stop early, parent sets
  keepRunning, and printouts occur with invocation counts. 
  zero deadline: deadline = 0, ensures immediate stop, verify output.
  Large size: stress recursion, discover max size before overflow. report
  observed size.
  cross-platform consistency: run A.1 on WINDOWS, A.2&A.3 on Linux, and A.4 on
  UNIX.
  Cancellation edge cases: run with pthread_cancel and verify parent prints
  stats for cancelled threads.
  Signal handler safety test: make handler use write() only for printing
  in handler. Test that counts are printed correctly upon SIGALRM.
